# 03 Module Design

All names below are frozen public module identifiers. A module may depend only on the listed lower-level or peer contract; direct circular dependencies are forbidden. Interfaces are versioned JSON-RPC methods, WebSocket events, C++/Rust abstract interfaces, or SDK contracts as indicated.

| Module | Position and responsibilities | Input / output / interface | Allowed dependencies; forbidden dependencies | Process / persistence / security | Error range / tests / phase |
| --- | --- | --- | --- | --- | --- |
| `astra-shell` | Task desktop, phone window, projection status, system state, input entry. Never performs inference, storage, policy decisions, or update work. | Input events and view models; rendered views and intent requests; QML view contract. | `display`, `input`, `common`; not `ai-runtime`, `file`, `security`, `update` directly. | `astra-shell`; ephemeral UI state; restricted. | 1000/4000; component, accessibility, E2E; P1. |
| `astra-spatial` | Coordinates, scene graph, anchors, surfaces, observer view, spatial-object lifecycle. | Sensor poses and scene commands; anchors/scenes; spatial API. | `hal`, `common`; not `shell`, `policy`, cloud. | `astra-core-service`; calibrated-scene metadata; restricted. | 3000; unit, component, hardware; P3. |
| `astra-ai-runtime` | AI lifecycle, inference context, capability registration, local/cloud invocation coordination. | Task inference requests; typed AI responses; AI runtime API. | `intent`, `model-router`, `memory`, `security`, `common`; not `shell`, HAL direct. | `astra-ai-service`; transient contexts; sensitive. | 2000; unit, integration, security; P2. |
| `astra-intent` | Natural-language parsing, structured intent, confidence, parameters, ambiguity. | User text/audio transcript; `Intent`; intent API. | `common`, approved model API; not task executor or projection. | `astra-ai-service`; transient parse record; sensitive. | 2000; unit, contract, regression; P2. |
| `astra-task-engine` | Task decomposition, orchestration, state, retry, cancellation, rollback, pause/resume. | `Intent` and capability context; `Task` state/events; task API. | `intent`, `security`, `policy`, service contracts, `common`; not UI or HAL direct. | `astra-core-service`; durable task state; sensitive. | 2000; state-machine, integration, recovery; P2. |
| `astra-model-router` | Local/cloud choice, privacy gate input, performance, cost, degradation. | Model request/classification; selected model route; routing API. | `policy`, `security`, `common`; not UI and not raw projection. | `astra-ai-service`; route metrics; high. | 2000; policy, latency, fallback; P2. |
| `astra-memory` | Context, task memory, preferences, long-term and sensitive-memory isolation/deletion. | Memory commands; scoped records; memory API. | `security`, `policy`, `common`; not UI, projector, cloud direct. | `astra-ai-service`; encrypted memory store; high. | 2000/6000; unit, deletion, security; P2. |
| `astra-projection` | Projector discovery, sessions, privacy check request, start/stop, output target selection. | Projection request; session state; projection API. | `display`, `policy`, `security`, `hal`, `audit`; not `shell` or model direct. | `astra-projection-service`; session records; high. | 4000; contract, hardware, privacy; P4. |
| `astra-display` | Phone and projector outputs, compositing boundary, display state, resolution and refresh. | Render surfaces; display targets/events; display API. | `hal`, `common`; not policy, AI, file. | `astra-core-service`; display preferences; restricted. | 4000; component, hardware; P1. |
| `astra-input` | Normalize touch, voice, gesture, eye, and camera-derived inputs. | Device samples; classified input events; input API. | `hal`, `security`, `common`; not shell policy or task engine. | `astra-core-service`; no raw retention by default; high. | 7000; unit, latency, hardware; P3. |
| `astra-file` | Managed file metadata, access mediation, and durable content operations. | File capability request; handles/metadata; file API. | `security`, `policy`, `audit`, `common`; not shell or HAL. | `astra-core-service`; application data; high. | 6000; unit, permission, recovery; P5. |
| `astra-device` | Device inventory, connectivity state, and managed external-device access. | HAL device signals; device status; device API. | `hal`, `security`, `audit`, `common`; not UI or AI direct. | `astra-core-service`; device registry; restricted. | 7000; contract, hardware; P5. |
| `astra-media` | Media sessions and controlled playback/capture routing. | Media command; session state; media API. | `security`, `policy`, `hal`, `audit`; not shell. | `astra-core-service`; media metadata; high. | 4000/7000; component, privacy, hardware; P5. |
| `astra-notification` | Policy-filtered system notifications and delivery state. | Service events; notification model; notification API. | `policy`, `security`, `audit`, `common`; not HAL. | `astra-core-service`; notification history; restricted. | 1000; unit, integration, accessibility; P5. |
| `astra-security` | Identity, capability tokens, permission checks, security context, credentials, trust state. | Principal/action/resource request; allow/deny and token; security API. | `common`; not UI, AI, app runtime, HAL adapters. | `astra-security-service`; protected credentials; critical. | 5000; unit, adversarial, integration; P4. |
| `astra-policy` | Privacy, projection, AI-tool, data-access policy decisions. | Context and classification; signed decision; policy API. | `security`, `common`; not callers' internal implementations. | `astra-security-service`; policy rules; critical. | 4300/5000; unit, matrix, security; P4. |
| `astra-audit` | System, AI, projection, permission-denial, and update audit records with buffering. | Audit event; immutable event receipt; audit API. | `security`, `common`; not caller business data stores. | `astra-audit-service`; append-only audit store; critical. | 1000/5000; integrity, recovery, security; P4. |
| `astra-settings` | Validated configuration lifecycle and explicit settings changes. | Versioned config; validated snapshot/events; settings API. | `security`, `audit`, `common`; not UI persistence direct. | `astra-core-service`; config store; high. | 1000; schema, migration, integration; P5. |
| `astra-update` | Version check, signed package verification, atomic update and rollback state. | Package metadata; update status; update API. | `security`, `audit`, `common`, HAL platform adapter; not shell. | `astra-update-service`; update state; critical. | 8000; signature, rollback, hardware; P5. |
| `astra-runtime` | Application isolation, lifecycle, API mediation for Native, Web, WASM, and Skills. | Signed package and calls; constrained runtime events; runtime API. | `security`, `policy`, `sdk`, `common`; not privileged services direct. | `astra-core-service`; app state; high. | 1000/5000; sandbox, contract, E2E; P6. |
| `astra-sdk` | Stable developer contract definitions, generated clients, examples, compatibility policy. | API definitions; versioned SDK artifacts; SDK API. | `protocols`, `schemas`, `common`; not service internals. | Build-time package; no device data; public. | 9000; contract, compatibility; P6. |
| `astra-hal` | Platform-independent device interfaces and platform adapter selection. | Abstract device commands/events; typed HAL contract. | `common`; not UI, policy, AI, runtime. | Per service adapter; device state only; restricted. | 7000; fake-adapter, integration, hardware; P7. |
| `astra-common` | Shared primitives: identifiers, result types, time, schema/version helpers, tracing. | Typed primitives; portable library API. | No product module dependencies. | Linked library; no persistence; internal. | 1000/9000; unit, portability; P0. |

Module-to-process allocation is authoritative in [04 Process Model](04-process-model.md). The design uses 23 modules.
