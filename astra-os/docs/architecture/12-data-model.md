# 12 Logical Data Model

This is a logical model, not a database design. IDs are UUID strings unless stated otherwise. Persistent records have schema versions and migration rules; sensitive records are encrypted at rest and never enter ordinary logs.

| Entity | Field contract: type, required/default, enum | Lifecycle / sensitivity / persistence / owner / compatibility |
| --- | --- | --- |
| `User` | `id: UUID` required; `display_name: string` required; `state: enum(ACTIVE,DISABLED)` default `ACTIVE`. | Provisioned to disabled; restricted; secure store; security; additive fields only. |
| `Device` | `id: UUID` required; `kind: enum(DISPLAY,CAMERA,SENSOR,PROJECTOR,AI_ACCELERATOR)` required; `trust_state: enum(UNTRUSTED,TRUSTED,REVOKED)` default `UNTRUSTED`. | Discovered to retired; restricted; device registry; device; enum additions negotiate by version. |
| `Application` | `id: UUID` required; `manifest_version: semver` required; `signature: string` required; `state: enum(DISABLED,ENABLED)` default `DISABLED`. | Installed to removed; restricted; runtime store; runtime; manifest version negotiation. |
| `Capability` | `id: UUID` required; `action: string` required; `resource: string` required; `expires_at: timestamp` required; `remaining_uses: integer` default `1`. | Granted to expired/revoked; high; security store; security; immutable grant semantics. |
| `Intent` | `id: UUID` required; `kind: string` required; `confidence: number` default `0`; `parameters: object` default `{}`; `state: enum(PARSED,AMBIGUOUS,RESOLVED,REJECTED)` default `PARSED`. | Parsed to resolved/rejected; sensitive; task record; intent; new optional parameters only. |
| `Task` | `id: UUID` required; `intent_id: UUID` required; `state: enum(PENDING,RUNNING,PAUSED,CANCELLED,SUCCEEDED,FAILED,ROLLED_BACK)` default `PENDING`. | Pending to terminal state; sensitive; durable task store; task-engine; state-machine versioned. |
| `TaskStep` | `id: UUID` required; `task_id: UUID` required; `ordinal: integer` required; `state: enum(PENDING,RUNNING,COMPENSATED,SUCCEEDED,FAILED)` default `PENDING`. | Created to compensated; sensitive; task store; task-engine; append-only execution fields. |
| `ProjectionSession` | `id: UUID` required; `target_id: UUID` required; `privacy_level: enum(PUBLIC,ROOM_ONLY,AUTHORIZED_PERSON,PRIVATE_SCREEN_ONLY,NO_PROJECTION)` required; `status: enum(REQUESTED,ACTIVE,CLOSED,DENIED)` default `REQUESTED`. | Requested to closed; high; session/audit store; projection; privacy enum must negotiate. |
| `DisplayTarget` | `id: UUID` required; `kind: enum(PHONE,PROJECTOR,EXTERNAL)` required; `resolution: string` required; `refresh_rate: number` required. | Detected to unavailable; restricted; display state; display; capability flags additive. |
| `SpatialScene` | `id: UUID` required; `coordinate_space: enum(DEVICE,ROOM,ANCHOR)` required; `version: integer` default `1`. | Created to disposed; restricted; scene store; spatial; format version required. |
| `SpatialAnchor` | `id: UUID` required; `scene_id: UUID` required; `pose: object` required; `confidence: number` default `0`. | Tracked to expired; restricted; calibrated metadata; spatial; pose schema versioned. |
| `SceneObject` | `id: UUID` required; `scene_id: UUID` required; `privacy_level: enum(PUBLIC,ROOM_ONLY,AUTHORIZED_PERSON,PRIVATE_SCREEN_ONLY,NO_PROJECTION)` required; `transform: object` required. | Created to removed; high; scene store; spatial; privacy mandatory in all versions. |
| `ModelDescriptor` | `id: UUID` required; `class: enum(LOCAL,CLOUD)` required; `capabilities: array[string]` default `[]`; `data_policy: enum(LOCAL_ONLY,CLOUD_ALLOWED)` required. | Registered to unavailable; restricted; model manifest; model-router; contract version required. |
| `AIModel` | `descriptor_id: UUID` required; `provider: string` required; `availability: enum(AVAILABLE,UNAVAILABLE,RETIRED)` default `UNAVAILABLE`. | Available to retired; restricted; model registry; ai-runtime; provider fields additive. |
| `MemoryRecord` | `id: UUID` required; `scope: enum(TRANSIENT,TASK,USER,LONG_TERM)` required; `classification: enum(PUBLIC,PRIVATE,RESTRICTED)` default `PRIVATE`; `retention: timestamp` required. | Created to deleted; high; encrypted memory store; memory; deletion semantics preserved. |
| `AuditEvent` | `id: UUID` required; `timestamp: timestamp` required; `event: string` required; `actor: UUID` required; `result: enum(SUCCESS,DENIED,FAILED)` required; `hash: string` required. | Appended to retained/exported; critical; append-only audit store; audit; event schema versioned. |
| `ConfigurationRecord` | `id: UUID` required; `name: string` required; `version: integer` required; `source: enum(DEFAULT,SYSTEM,DEVICE,ENVIRONMENT,ARGUMENT)` required; `hash: string` required. | Validated to superseded; high; config store; settings; schema migration required. |
| `UpdatePackage` | `id: UUID` required; `version: semver` required; `signature: string` required; `compatibility: object` required; `state: enum(STAGED,INSTALLED,FAILED)` default `STAGED`. | Staged to installed/failed; critical; update store; update; package format negotiated. |
| `SystemVersion` | `system: semver` required; `protocol: semver` required; `config: integer` required; `database: integer` required; `sdk: semver` required; `model_interface: semver` required. | Released to superseded; restricted; version store; update; independently versioned fields. |

Ownership prevents duplicate authoritative stores. Retention, deletion, backup, cache, synchronization, and migration rules are elaborated in [Data Design](../design/AstraOS-Data-Design-v1.0.md).
