# 20 Future Hardware Architecture

The target terminal combines an ARM64 Linux compute unit, phone-class private display, optional external projector, camera and sensor suite, local AI accelerator where available, power and thermal controls, and audio/network peripherals. The HAL isolates display, camera, sensor, projector, power, and acceleration driver differences.

P7 validates ARM64 Linux development-board adaptation. P8 validates external projection and camera engineering hardware. P9 validates a portable spatial-AI terminal. P10 evaluates phone-class hardware and manufacturing. The design explicitly does not assume custom chips, custom baseband, or a custom kernel.
