# P3 Fallback And Safety

Camera denial, disconnect, invalid input, lost target, unusable quality, invalid homography, coordinate failure, or service loss clears the spatial overlay and requests the existing Shell projection path to hide sensitive content and pause or return to safe idle. Phone UI shows a stable reason and recovery action.

Simulation is the source fallback. Recovery requires a fresh detection or valid calibration; stale target geometry is never reused. P1 privacy policy and P2 stop/hide/status fallback remain available when P3 is absent.
