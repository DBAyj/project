# Astra Intent Service

The P2 intent service is an offline-first Python 3.12 process. It exposes strict intent contracts over a Unix Domain Socket and an explicit development HTTP endpoint. It does not call cloud AI providers or download model artifacts.

Production-local requests use JSON-RPC 2.0 at `runtime/intent/sockets/astra-intent.sock`. Development routes are `/health`, `/ready`, `/v2/intents/parse`, `/v2/intents/confirm`, `/v2/intents/reject`, `/v2/intents/supported`, `/metrics`, and WebSocket `/events`. Both transports require the runtime capability token generated by `scripts/run_p2.sh`; the token is never committed or logged.

Use repository targets `make p2-configure`, `make p2-build`, `make p2-test`, `make p2-test-security`, `make p2-test-performance`, `make p2-run`, and `make p2-stop`. The service remains portable to ARM64 Linux and has no AppKit, SwiftUI, cloud-model, camera, projector, or P3 dependency.
