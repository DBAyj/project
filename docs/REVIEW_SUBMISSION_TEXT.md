# 微信小程序提审文本模板

以下内容可复制到微信公众平台的版本描述、功能说明、审核备注或测试说明中。上线前请把占位内容替换为真实版本号、房间号和服务域名。

## 版本描述

霓虹街区首个多人对战版本。支持单人练习、本机双人和 WebSocket 房间多人对战。

## 功能说明

霓虹街区是一款俯视角街机对战小程序游戏。玩家通过左半屏移动、右半屏瞄准并开火，在竞技场中拾取回血和射速道具，击败对手获得分数。

当前版本包含：

- 单人练习：玩家可与 AI 对手进行基础对战。
- 本机双人：同一台设备左右半屏分别控制两名玩家。
- 在线对战：玩家输入昵称和房间号，连接线上 WebSocket 对战服务进入同一房间。

## 审核测试步骤

1. 打开小程序首页。
2. 点击“单人练习”，验证移动、瞄准、开火、道具拾取和计分。
3. 返回后点击“本机双人”，验证左右半屏分别控制两名玩家。
4. 输入昵称和测试房间号 `review-room`。
5. 点击“在线对战”，两个客户端使用同一房间号可进入同一房间进行实时对战。

## 审核账号

当前版本不需要账号登录，也不读取微信头像、昵称、手机号、位置、相册、通讯录、录音或摄像头权限。

如需在线对战测试，请使用固定测试房间号：

```text
review-room
```

## 隐私与数据说明

当前版本不采集微信个人资料。多人对战只使用用户手动输入的昵称、房间号和对局内操作状态，用于房间内实时同步。示例服务不持久化保存对局数据，房间无人后会清理内存状态。
